Telegraph 정리
- 모든 몬스터의 Telegraph를 아래와 같은 패턴으로 재 정리해서 적용한다. 
- 모든 몬스터의 스킬 영향 범위는 아래 트레일과 사이즈 및 구현방식을 매칭해서 결정된다. 

0. 무표시
- TypeName = "None"
- 이 스킬은 텔레그래프를 표시하지 않는다. 

1. 직선 박스형 
- TypeName = "StretchBox"
- 시작점 -> 목표점으로 길게 늘어나는 박스. 기본오브젝트는 1x1 평면 박스로, 스케일을 곱해서 사이즈를 정한다. 
- 시작점을 Pivot 으로 하는 사각형 게임오브젝트를 사전에 만든다. 축 방향으로 스트래치해서 너비와 길이를 결정한다. 

2. 자기중심 원형
- TypeName = "SelfCircle"
- 내 발밑에 원형. 기본오브젝트는 지름 1미터 원형으로, 스케일을 곱해서 사이즈를 정한다. Pivot점은 원의 중심이다.

3. 목표 원형
- TypeName = "TargetCircle"
- 목표지점에 원형. 기본오브젝트는 지름 1미터 원형으로, 스케일을 곱해서 사이즈를 정한다. Pivot점은 원의 중심이다.

4. 자기중심 방사형
- TypeName = "StretchArc30",  "StretchArc45", "StretchArc60", "StretchArc90", "StretchArc120", "StretchArc135", "StretchArc180", "StretchArc210" 
- 시작점 -> 목표점으로 길게 늘어나는 아크. 기본으로는 길이 1x1 박스를 스케일을 곱해서 사이즈를 정한다. 
- 아크의 중심점을 Pivot 으로 하는 게임오브젝트를 각도별로 사전에 만든다. 단순 스케일로만 확대 축소가 가능하다.
- 이름의 "StretchArc"뒤의 숫자는 각도를 의미한다. 

5. 자기타겟연결형
- TypeName = "TargetConnect"
- 시작점->목표점 연결하는 Trail 이 Duration 동안 지속된다.
