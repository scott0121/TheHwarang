# 구현 완료 가정 시 게임 평가 (초안)

전제: 문서 내용이 모두 구현되고 전투 품질이 평균 이상인 경우입니다. 개발 인원과 예산은 모르므로 별도로 가정하지 않았습니다. 매출·위시리스트 같은 수치 예측은 근거가 없어 하지 않습니다. 유사작 비교는 제 지식 기준이라 최신 출시작이 빠졌을 수 있습니다.

## 1. 항목별 평가

| 항목                  | 점수(10) | 근거                                                         |
| --------------------- | -------- | ------------------------------------------------------------ |
| 전투 코어 차별성      | 5.5      | 활 + 단검 패링 + 투사체 반사는 조합으로는 괜찮지만, 요소 하나하나는 기존 작품에 이미 있음 |
| 빌드 다양성·반복 재미 | 4.5      | Boon 12종은 이 장르 기준으로 적음. 무기 종류 시스템 없음     |
| 서사·감정선           | 7.5      | 아랑, 충전 화살 수미상관, 3장 반전은 이 장르 평균 이상       |
| 개성·정체성           | 6.5      | 삼국유사 설화와 보석 토끼는 개성 있음. 룸 구조·Boon 등 시스템 쪽은 평범함 |
| 구조 완성도           | 6        | 성장·리셋·가호 규칙은 정리됨. 엔드게임이 약함                |
| 마케팅 훅             | 5.5      | 소재는 눈에 띄지만 해외 인지도가 없고, 한 줄 훅의 힘이 중간 정도 |
| 제작 현실성           | 4        | 3D 보스·몬스터 약 45종, 룸 템플릿, Spine/Live2D 컷신은 소규모 팀에 무거움 |
| **종합**              | **약 6** | 장르 평균 이상이지만 상위권 진입 조건은 미충족               |

## 2. 유사작 대비 위치

| 비교작            | 겹치는 요소                     | 우리가 열세인 부분                 | 우리가 유리할 수 있는 부분                               |
| ----------------- | ------------------------------- | ---------------------------------- | -------------------------------------------------------- |
| Hades 계열        | 탑다운 3D, 거점 복귀, 서사 중심 | 빌드 수, 대사량, 연출, 전투 피드백 | 설화 기반의 한 편으로 완결되는 서사, 패링 반사 중심 전투 |
| Dead Cells        | 패링, 액션 템포                 | 무기·빌드 규모, 속도감             | 원거리 + 패링 조합                                       |
| Enter the Gungeon | 탄막, 일부 탄 반사              | 무기·아이템 시너지 수              | 서사 밀도                                                |
| Death's Door 류   | 보스 중심의 소규모 액션         | 월드 설계 완성도                   | 로그라이크 반복 구조                                     |

**차별성 판단.** 시스템 하나만으로는 차별점이 약합니다. 차별점은 "패링 반사 전투 + 한국 설화 서사"의 결합에서 나옵니다. 이 결합이 전투 영상과 스토어 페이지에서 한눈에 전달되어야 합니다.

## 3. 재미 요소 분석

**강점**

- 푸른 탄 반사와 금색 패링 그로기는 읽기 쉬운 규칙이고, 보스마다 패링 활용처가 지정되어 있음.
- 보스 기믹이 서사와 맞물림(3-4 아랑 환영 방패, 5-3 미러전, 6-3 최종 충전).
- 가호로 어려운 스테이지에서 이탈하는 플레이어를 줄일 수 있음.

**약점**

- **재플레이 동기가 약함.** 22스테이지가 고정 순서이고, 기억의 조각은 최초 클리어 1회만 지급됩니다. 클리어한 스테이지를 다시 할 이유가 거의 없어서 로그라이크보다 "스테이지 클리어형 액션"에 가깝습니다.
- **빌드 깊이 부족.** Boon 계열은 활·단검·보옥 3축뿐입니다. 이 장르는 수십 종 이상에서 시너지가 나오는 경우가 많습니다.
- **원거리 다양성이 문서에 없음.** 처음 말씀하신 "원거리 공격을 다양하게"에 해당하는 무기·활 종류 시스템이 없고, 변화는 Boon에만 의존합니다.
- **스테이지당 10~15분 + 사망 시 처음부터 리셋.** 고난도 보스에서 반복할 때 피로가 큽니다. 가호가 이를 얼마나 상쇄하는지는 프로토타입 전에는 알 수 없습니다.
- 챕터마다 3단락 + 컷신 패턴이 반복되어 중반 이후 예측 가능해질 수 있음.

## 4. 개성 요소

| 요소             | 평가                                                         |
| ---------------- | ------------------------------------------------------------ |
| 설화 소재        | 국내에서는 호감 요인. 해외에서는 설명 비용이 들고 소재 자체가 구매 이유가 되지는 않음 |
| 아랑·죄책감 서사 | 가장 강한 자산. 단, 텍스트 중심 전달이라 연출 품질에 의존함  |
| 보석 토끼        | 캐릭터 상품성은 있으나 대사량이 약 55라인 수준이라 정서적 비중이 아직 작음 |
| 최종 충전 구간   | 기억에 남을 장면 후보. 구현 품질이 곧 평가를 좌우함          |

## 5. 마케팅 요소

| 항목                    | 평가                                                         |
| ----------------------- | ------------------------------------------------------------ |
| 스토어 태그 적합성      | 로그라이크, 액션, 탑다운, 스토리 리치, 신화. 경쟁이 매우 많은 구간 |
| 영상(GIF·트레일러) 소재 | 투사체 반사 장면과 보스 패링 장면이 가장 유력                |
| 해외 장벽               | "거타지"라는 이름과 삼국유사의 인지도가 낮아 영문 소개 문구와 한 줄 설명에 의존 |
| 서사 위주 홍보의 한계   | 서사의 핵심 반전(3장)은 홍보에 쓰기 어려워 마케팅 소재가 전투에 몰림 |
| 단일 출시 방식          | 얼리 액세스처럼 피드백을 모으며 홍보할 구간이 없어 출시 전 위시리스트 확보가 핵심 변수 |

## 6. 구현 품질별 예상

| 시나리오 | 조건                                                | 예상 위치                                                 |
| -------- | --------------------------------------------------- | --------------------------------------------------------- |
| 상       | 전투 손맛이 Hades·Dead Cells에 근접, 컷신 연출 호평 | 서사형 인디 로그라이크 중 상위권                          |
| 중       | 전투는 무난, 콘텐츠는 문서 그대로                   | 장르 팬 중 일부에게 호평, 다수는 이탈. 대중 흥행은 어려움 |
| 하       | 패링 판정·가독성 불안정, 후반 챕터 반복감           | 리뷰에서 "짧고 반복적" 평가 가능성                        |

문서 그대로 구현하면 **중**이 가장 현실적이며, 이 문서만으로는 상으로 가는 요소가 부족합니다.

## 7. 우선순위 보강 제안

| 순위 | 항목                                                         | 이유                                                         |
| ---- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 1    | 반복 플레이 동기 추가 (재클리어 보상, 스테이지 변형, 무기·활 종류 선택) | 현재 가장 큰 구조적 약점이고, 원거리 다양성 요구도 함께 해결됨 |
| 2    | Boon 규모 확대 (런칭 시 최소 수십 종, 시너지 규칙 포함)      | 빌드 재미의 핵심                                             |
| 3    | 스코프 축소 검토 (열쇠지기 변형 재사용, 챕터당 룸 템플릿 감축, 스테이지 수 조정) | 제작 현실성 4점이 가장 낮은 항목                             |
| 4    | 한 줄 훅과 트레일러 시나리오를 프로토타입 단계에서 먼저 검증 | 단일 출시라 사전 인지도 확보가 필수                          |

최종 판단은 프로토타입의 패링·반사 전투 손맛을 외부 테스트한 결과에 따라 크게 달라집니다. 그 전까지의 평가는 문서 기준 추정입니다.
